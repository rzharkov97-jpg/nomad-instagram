Ты находишь трендовые Reels и делаешь по ним контент для гостиницы Nomad в Есике. Работаешь там, где запущен Claude Code: на ноутбуке Романа все файлы сохраняются в папку этого репозитория.

## 0. Проверка окружения
- `ffmpeg -version` и `python3 -c "import PIL"`. Если чего-то нет — скажи, как поставить (Windows: `winget install ffmpeg`, `pip install pillow`; macOS: `brew install ffmpeg`, `pip3 install pillow`), и остановись.
- Исходники лежат на Google Диске Романа (папка «21.10.2026», id 1DvkdxNhaNnPbWgNGi_kANZm_PMVrWCsW): ищи через `search_files` с `parentId`, качай через `download_file_content` — результат сохраняется в файл, достань `jq -r .content | base64 -d`. Прямые ссылки drive.google.com из облака закрыты. Перед монтажом сделай раскадровку (ffmpeg tile) и посмотри её — имена файлов не говорят, что на видео. Можно также класть исходники в `media/`. Если там пусто, используй готовые картинки из `posts/` и `stories/` и прямо скажи, каких кадров не хватает для тренда.
- Факты о гостинице бери из скилла `anthropic-skills:nomad-instagram-post`, не придумывай.

## 1. Поиск трендов
1. `vidiq_instagram_tiktok_outlier_search` — 2–3 запроса с разным `embeddingType`:
   - `format` — шаблоны монтажа (POV, «до/после», «ожидание/реальность», переходы под бит, «3 причины…»);
   - `hook` — крючки первых 3 секунд;
   - `concept` — темы: hotel room tour, mountain getaway, weekend trip, couple staycation.
   `audienceQuery`: `Culture/Region: Kazakhstan, Almaty region, CIS; Global: false; Demographics: couples and families 20-45, weekend trips to the mountains, budget travel;`. Ищи на `ru` и `en`, последние 14–30 дней.
2. Выбери 3–5 лучших по `outlierScore` и свежести. Паттерном называй только то, что повторяется хотя бы у двух роликов.
3. По 1–3 лучшим запусти `vidiq_watch_shortform_content` (параллельно) и забери: раскадровку, тайминг склеек, текст на экране, **название трека/звука и автора**, темп (быстро/медленно, примерный BPM).

Покажи Роману короткую таблицу: тренд, ссылка, просмотры, звук, почему он подходит Nomad. Если Роман не выбрал сам — возьми лучший и продолжай.

## 2. Адаптация под Nomad
Сценарий на 7–20 секунд: крючок в первые 1–2 секунды, план кадров с таймингом (склейки на долях бита), текст на экране (короткий, в нижней трети, не под кнопками Instagram), финал — логотип/адрес/WhatsApp, как в `reels/2026-10-22-v3`.

## 3. Музыка
Сначала пробуй прикрепить трендовый звук прямо в Metricool: `instagramData.audioConfiguration.audioId` = «название исполнитель» из библиотеки Instagram. Если Metricool отвечает ошибкой доступа к аудиокаталогу — ставь пост с `autoPublish: false`: в назначенное время Роману придёт пуш, и он добавит звук в Instagram. Название звука обязательно в `post.md`.

Если нужны файлы для ручной публикации — две версии:
Чужую трендовую музыку в файл не вшивай: это нарушает авторские права, и Instagram глушит такие ролики. Поэтому:
- **`*_trend_silent.mp4`** — без звука, склейки по темпу трендового трека. Звук добавляется в приложении Instagram (поиск по названию трека). Через Metricool трендовый звук не прикрепить — эту версию Роман публикует сам с телефона.
- **`*_music.mp4`** — с оригинальной безлицензионной музыкой: `vidiq_generate_music` (жанр, настроение, инструменты, **точный BPM как у тренда**, `instrumental`, длительность = длине ролика), ждать через `vidiq_job_poll`, скачать WAV в папку ролика. Эту версию можно ставить в Metricool.

Склейки считай от BPM: одна доля = 60/BPM с; меняй кадр каждые 1–2 доли, акцент (вспышка, зум) на сильную долю.

## 4. Монтаж (ffmpeg)
1080×1920, 30 fps, H.264, `yuv420p`, `-movflags +faststart`, звук AAC 192k. Фото — с лёгким зумом (zoompan), видео — обрезать по 9:16. Обложка `cover.jpg` 1080×1920 с крупным крючком.
Проверка: `ffprobe` (длительность, разрешение, есть ли аудио) и 3–4 кадра через ffmpeg → Read: текст читается и не обрезан.

## 5. Сохранение на компьютере
Всё складывай в `reels/ГГГГ-ММ-ДД-тема/`:
- `nomad_<тема>_trend_silent.mp4`, `nomad_<тема>_music.mp4`, `music.wav`, `cover.jpg`;
- `post.md` — подпись (крючок, польза, призыв в WhatsApp, адрес), 5–10 хэштегов, название трендового звука и с какой секунды его ставить, ссылка на исходный тренд, рекомендуемое время публикации.

Скрипты монтажа — во временной папке, не в репозитории.

## 6. Выгрузка в Metricool
Если Роман сказал «сделай всё сам», ставь сразу; иначе после его «ставь»:
1. `git add reels/<папка> && git commit && git push origin main` — Metricool забирает видео по прямой ссылке `https://raw.githubusercontent.com/rzharkov97-jpg/nomad-instagram/main/reels/<папка>/<файл>`. Проверь `curl -I` → 200.
2. `getBrandSettings` → blogId; `getScheduledPosts` — не задвоить дату; `getBestTimeToPostByNetwork` — время (Asia/Almaty).
3. Ставь Reel (со звуком из каталога или с `autoPublish: false`; если звука нет — `_music.mp4`) с обложкой и подписью из `post.md` через `createScheduledPostForReview` (ревьюер r.zharkov97@gmail.com). Если тарифу Metricool это недоступно — `createScheduledPost` в черновик/на дату, о которой договорились.
4. В `post.md` допиши дату, время и ссылку `plannerUrl`.
